Wewnętrzny arkusz stylów

1. Gdzie jest wstawiany wewnętrzny arkusz stylów?

Wewnętrzny arkusz stylów jest wstawiany wewnątrz sekcji <head> dokumentu HTML. Znajduje się między znacznikami <style> i </style>. Umieszczenie go w <head> gwarantuje, że style będą załadowane zanim przeglądarką rozpocznie wyświetlanie zawartości strony.

2. Składnia teoretyczna

Struktura wewnętrznego arkusza stylów:

<head>
  <style type="text/css">
    selektor1 { cecha: wartość; }
    selektor2 { cecha: wartość; }
  </style>
</head>

3. Jakie mogą być selektory?

Selektory w wewnętrznym arkuszu stylów mogą być:

  • Selektory elementów: p, h1, div, span, body, a
  • Selektory klas: .className
  • Selektory identyfikatorów: #idName
  • Selektory uniwersalne: *
  • Selektory potomka: div p (paragraf wewnątrz div)
  • Selektory pseudo-klas: a:hover, p:first-child

4. Jakie mogą być cechy i wartości?

Cechy i wartości to podstawowe elementy deklaracji CSS:

  • Cechy: color, font-size, background-color, font-family, text-align, margin, padding, border, width, height itp.
  • Wartości: red, blue, #FF0000, 12px, 1.5em, Arial, center, left, right, 10px 20px itp.

Przykłady:

p { color: red; font-size: 14px; font-family: Arial; }
