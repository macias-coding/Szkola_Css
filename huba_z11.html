Rodzaje selektorów

  1. Selektory proste (selektor typu)
    1. Selektor elementu — bezpośrednie zastosowanie do znacznika, np. p, h1, div
    2. Selektor uniwersalny (*) — ma zastosowanie do wszystkich elementów na stronie
    3. Selektor grupy — wiele selektorów oddzielonych przecinkami, np. h1, h2, h3
  2. Selektory potomka i dziecka
    1. Selektor potomka (ancestor descendant) — element wewnątrz innego elementu, np. div p
    2. Selektor dziecka (direct child) — bezpośrednie dziecko, np. div > p
    3. Selektor braci (sibling) — elementy obok siebie, np. h1 + p
  3. Selektory atrybutów
    1. Prosty selektor atrybutu — element z danym atrybutem, np. a[href]
    2. Selektor atrybutu o określonej wartości — np. input[type="text"]
    3. Selektor atrybutu zawierający określony wyraz — np. a[href*="example"]
  4. Selektory specjalne
    1. Selektor klasy — element z daną klasą, np. .className (notation: .nazwa_klasy)
    2. Selektor ID — element z danym identyfikatorem, np. #idName (notation: #nazwa_id)
    3. Pseudoklasy — specjalne stany elementu
      1. :hover — gdy mysz najedzie na element
      2. :active — element jest aktywny
      3. :visited — odnośnik został odwiedzony
      4. :first-child — pierwszy element potomka
    4. Pseudoelementy — części elementu
      1. ::first-line — pierwsza linia tekstu
      2. ::first-letter — pierwsza litera tekstu
      3. ::before — przed zawartością elementu
      4. ::after — po zawartości elementu
