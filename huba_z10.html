Budowa selektora

1. Dwie części selektora

Każda reguła CSS składa się z dwóch części:

  • Selektor: określa do jakich elementów (znaczników) ma zostać przypisane formatowanie. Przykłady: p, h1, div, .klasa, #id
  • Deklaracja: umieszczona w nawiasie klamrowym {...} podaje formatowanie, czyli jakie cechy (właściwości) i ich wartości mają być zastosowane

2. Znaczenie nawiasów klamrowych {...}

Nawiasy klamrowe {...} zawierają deklarację, czyli wszystkie reguły formatowania dla danego selektora. Wszystkie cechy i wartości muszą być umieszczone między tymi nawiasami. Nawias otwierający { oznacza początek deklaracji, a zamykający } oznacza jej koniec.

p { color: red; font-size: 14pt; }

3. Cechy (właściwości)

Cecha (ang. property) to konkretny atrybut formatowania, który chcemy zmienić. Przykłady cech:

  • color — kolor tekstu
  • font-size — rozmiar czcionki
  • background-color — kolor tła
  • font-family — rodzina czcionki
  • text-align — wyrównanie tekstu
  • margin — margines zewnętrzny
  • padding — margines wewnętrzny
  • border — obramowanie

4. Wartości (właściwości)

Wartość (ang. value) to konkretne ustawienie danej cechy. Każda cecha ma ściśle wyszczególnioną listę wartości, które może przyjąć. Przykłady:

  • Dla color: red, blue, #FF0000, rgb(255,0,0)
  • Dla font-size: 12px, 1.5em, 20pt, large
  • Dla text-align: left, right, center, justify
  • Dla background-color: white, #FFFFFF, rgb(255,255,255), yellow

5. Znaczenie średnika — kiedy jest obowiązkowy?

Średnik (;) oddziela poszczególne deklaracje cecha:wartość w obrębie jednej reguły. Średnik jest obowiązkowy między każdą parą cecha:wartość, gdy jest więcej niż jedna. Na końcu ostatniej cechy średnik nie jest konieczny, ale jest dobrą praktyką go umieszczać.

p { color: red; font-size: 14pt; text-align: center; }

W powyższym przykładzie średniki oddzielają trzy cechy. Ostatni średnik po text-align: center nie jest obowiązkowy, ale zaleca się go umieszczać dla konsystencji.
