Cechy modyfikowania formatowania w HTML oraz CSS

w HTML w CSS
modyfikacja wyglądu elementów strony jest bardzo żmudna, atrybuty i znaczniki są porozrzucane w różnych miejscach kodu rozdzielenie struktury i prezentacji; wszystkie polecenia formatowania można umieścić w jednym miejscu

Nowe możliwości CSS

  1. Dokumenty pisane z wykorzystaniem arkuszy stylów są zwykle bardziej przejrzyste i krótsze.
  2. Style pozwalają w łatwy sposób zarządzać całą serią dokumentów poprzez stosowanie zewnętrznych arkuszy stylów.
  3. Dzięki możliwości stosowania klas selektorów znacznie oszczędzamy sobie pisania.
  4. Możliwość stosowania różnorodnych jednostek oraz sposobów definiowania kolorów.
  5. Różne wartości pogrubienia czcionki oraz dodatkowe możliwości formatowania tekstu.
  6. Dodatkowe możliwości określenia wyglądu dokumentów podczas ich drukowania.

Wady CSS

  1. Składnia jest nietolerancyjna na błędy, co utrudnia poprawki.
  2. Brak sygnalizacji błędów podczas wykonywania styli CSS oraz ich realizacji.
  3. Różne przeglądarki mogą obsługiwać CSS odmiennie.
