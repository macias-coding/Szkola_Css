Styl zewnętrzny

1. Składnia teoretyczna stylu zewnętrznego

Zewnętrzny arkusz stylów zawiera same reguły CSS:

selektor1 { cecha: wartość; }
selektor2 { cecha: wartość; }
selektor3 { cecha: wartość; cecha2: wartość2; }

2. Gdzie wstawiany jest styl zewnętrzny?

Styl zewnętrzny jest podłączany za pomocą znacznika <link> umieszczonego w sekcji <head> dokumentu HTML. Znacznik <link> odpowiada za powiązanie pliku CSS. W jednym dokumencie HTML <link> może występować wielokrotnie, pozwalając na dołączenie wielu arkuszy stylów. Podłączenie odbywa się poprzez określenie ścieżki do pliku CSS w atrybucie href.

<head>
  <link href="style.css" rel="stylesheet" type="text/css">
</head>

3. Najprostsza forma wstawiania stylu zewnętrznego

<link href="nazwa_pliku.css" rel="stylesheet" type="text/css">

4. Ile arkuszy styli może być dołączanych do jednego dokumentu HTML?

Do jednego dokumentu HTML można dołączyć wiele arkuszy styli (teoretycznie nieskończoną liczbę). Zasadą, którą należy zachować przy większej ilości dołączanych styli, jest zasada kaskadowości — style dołączone później (niżej w kodzie) mogą nadpisywać style dołączone wcześniej (wyżej w kodzie). Style o wyższym priorytecie ważności mają pierwszeństwo.

5. Co się dzieje w przypadku konfliktów?

W przypadku konfliktów, gdy te same style są definiowane w różnych arkuszach stylów podłączonych do tego samego dokumentu, stosowana jest zasada kaskadowości. Style dołączone później (ostatnie w kodzie) mają wyższy priorytet i nadpisują poprzednie definicje. Jeśli chcemy wymusić priorytet danego stylu, możemy użyć deklaracji !important.

6. Jak są tworzone i edytowane pliki arkuszy z użyciem edytora tekstowego?

Pliki arkuszy CSS są tworzone i edytowane w zwykłych edytorach tekstowych (Notepad, Notepad++, VS Code). Zawsze muszą mieć rozszerzenie .css. Edytor tekstowy pozwala na pełną kontrolę nad kodem i jest uniwersalnym narzędziem dla każdego programisty.

7. Jak są tworzone i edytowane pliki arkuszy z użyciem specjalnego edytora CSS?

Specjalne edytory CSS (TopStyle, BalthisarCascade, Cascade DTP) oferują graficzny interfejs i wskaźniki błędów. Pozwalają na szybsze pisanie kodu dzięki autocompleteniu i podpowiedziom. Niektóre edytory oferują podgląd na żywo zmian w stylu.

8. Jakie rozszerzenie posiadają plik będący zewnętrznym arkuszem styli?

Plik będący zewnętrznym arkuszem styli ma rozszerzenie .css (Cascading Style Sheet). Przykład: style.css, layout.css, huba_z6.css

9. Jakie są zalety zewnętrznego arkusza styli?

  • Separacja zawartości od prezentacji: Struktura HTML jest oddzielona od stylów CSS, co czyni kod bardziej przejrzystym i łatwym do utrzymania.
  • Możliwość wielokrotnego użytku: Jeden arkusz CSS można podłączyć do wielu dokumentów HTML, co pozwala na spójny wygląd całej witryny i łatwiejsze wprowadzanie zmian globalnych.

10. Uwagi na temat pisania w CSS

  • CSS dopuszcza zarówno duże, jak i małe litery
  • Białe znaki (spacje, tabulacje, znaki nowej linii) nie wpływają na działanie
  • Komentarze w CSS: /* komentarz */
  • Średnik (;) oddziela deklaracje i jest obowiązkowy między każdą parą cecha:wartość
  • Zawsze sprawdzaj efekty w kilku przeglądarkach, ponieważ różne przeglądarki mogą obsługiwać CSS odmiennie
